LUD-22: Alternative payment methods.
====================================

`author: Francis Pouliot`

---

## Service response

The `payRequest` response MAY include a `payment_methods` field:

```typescript
{
    // ...LUD-06 fields...
    "payment_methods": [
        { "code": string, "name": string }
    ]
}
```

`code` is the routing key sent back on the callback. `name` is a display label.

Lightning is the LUD-06 default and MUST NOT appear in `payment_methods`.

### Registered codes

| `code` | Method |
|---|---|
| `L-BTC`  | Liquid Bitcoin |
| `BTC`    | Bitcoin on-chain |
| `BTC-SP` | Bitcoin Silent Payments (BIP-352) |

New codes are added by PR to this LUD and MUST specify the callback response shape.

## Wallet callback

```
<callback>?amount=<milliSatoshi>[&payment_method=<code>]
```

- Absent: standard LUD-06.
- Present and unsupported: `{ "status": "ERROR", "reason": "unsupported payment method" }`.
- `amount` is millisatoshi; `amount % 1000 != 0` MUST error.

LUD-06 `minSendable` / `maxSendable` apply to every method.

## Service callback response

### `payment_method` absent

LUD-06: `{ "pr": string, "routes": [] }`.

### `payment_method=L-BTC`

```json
{
    "onchain": {
        "address": string,
        "amount_sat": number,
        "bip21": string
    }
}
```

`address` MUST be a confidential Liquid address.
`bip21` is `liquidnetwork:<address>?amount=<btc_decimal>&assetid=<lbtc_asset_id>`.

### `payment_method=BTC`

```json
{
    "onchain": {
        "address": string,
        "amount_sat": number,
        "bip21": string
    }
}
```

`bip21` is `bitcoin:<address>?amount=<btc_decimal>`.

### `payment_method=BTC-SP`

```json
{
    "onchain": {
        "silent_payment_addr": string,
        "amount_sat": number,
        "bip21": string
    }
}
```

`silent_payment_addr` is a BIP-352 silent-payment address.
`bip21` is `bitcoin:<silent_payment_addr>?amount=<btc_decimal>`.

## Notes

- The LUD-06 `metadata` description-hash check applies to Lightning only.
- Service ordering of `payment_methods` is not authoritative.
